# General Cache Subsystem: RTL design and Verification IP

This is a personal project to design a complete cache subsystem with generic features that are expected in a state of the art processor. Along with the design it will contain verification collateral that is used to verify the design. The project will continue to grow and have offshoots for large optimizations and branches for versions, smaller optimizations.

## Top Level Design

The project currently has a 2 stage Cache: L1 and L2. It has a single parameterized L1 cache and parameterized L2 cache.

## Current Goal / Spec

The current goal of the IP is to replicate all features from the [Cache Simulator](https://github.com/RachitGupta23/Cache_simulator) project and achieve the same performance in RTL design.
